# flock_knows_what_birds_dont
This repository contains four MATLAB files for simulating flocking and escaping behaviour from predators in birds modelled as active inference agents.

- Author: Domenico Maisto
- Code developped with MATLAB 2024b
- Run 'script_execution.m' to start a simulation
- Run 'getMarkovBlanketOfFlock.m' to get a statistical characterisation of the birds with respect to a flock
