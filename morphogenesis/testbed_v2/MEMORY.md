# MEMORY.md — Gate G2 (handedness memory: "the body remembers, a cell forgets")

Labels: ESTABLISHED / PROVISIONAL / NOT DONE. Code `code/g2cfg.py`, `g2a.py`, `g2b.py`, `g2c.py`; data `data/g2_*.json`.

## Declared parameters
First choice from the spec's design rule (w = 1 isolated cell): k_h = 0.1, β_E = 4 (k_hβ = 0.4), π_d = 0.02, π_ψ = 0.10, r = 0.05. Template: w̄² = 15.34, w ∈ [2.60, 4.91]; G₁ = 0.048 < 4r = 0.2 ✓, G_mem = k_hβ(π_d + π_ψ w̄²) = 0.62 ≥ 8r = 0.4 ✓ (mean-field bistable by memory alone, l* = 2.34, ΔU = 0.28).
**Result: the isolated cell did not forget** (relaxed to l = 1.06 at rate 2.4e−4, prediction 0.076).
**Diagnosis (ESTABLISHED, derived and checked):** the spec's G₁ takes the isolated cell's w = 1, but a cell that holds place k expects Ψ* = w_k D* with w_k ∈ [2.6, 4.9] and senses only its own secretion. Its d settles at a = (π_d + π_ψ w_k)/(π_d + π_ψ) times the form's code, and the effective gain is **G_iso(k) = k_hβ(π_d + π_ψ w_k)²/(π_d + π_ψ)** (here 0.34–0.85 > 4r). For a uniform body there is no amplification (d = D), so G = k_hβ(π_d + π_ψ w̄²) is right. Consequence: G_iso(w_max)/G = w_max²/w̄² = 1.57 at π_d = 0 — the rule "G₁ < 4r and G ≥ 8r" cannot hold for cells at the high-w places with memory-only coupling (ratio can reach only 2.26 at the lowest-w place).
**Revised point (knobs within declared ranges): π_d = 0.01, π_ψ = 0.04, r = 0.10, k_h = 0.1** (β_E = 4). Then G_iso(k) ∈ [0.10, 0.34] < 4r = 0.4 for every place (isolated cells forget wherever they sit), G_mem = 0.25 (< 4r: **memory alone is NOT bistable**), mean morphological gain G_morph = 6.6 (per place 0 … 24.2). Design rule (f): G₁ < 4r ✓ (also G_iso); **G ≥ 8r ✗ for the memory channel alone** (0.25 vs 0.8); ✓ only when the morphological evidence is counted (G_tot = 6.8 = 68 r).

Isolated cell and two cells 40 apart, from l = ±3: **l → 0 (|l| < 1e−4 after 600 tu) in all 4 runs**. Rate (first 50 tu): 0.0317 (place 8, w = 4.91) and 0.0328 (place 22, w = 2.60). ## (c) The body remembers (ESTABLISHED)
Bodies L and R (seeded, consistent) held 2000 tu deterministically: stay in form. ρ: L mean 0.78, bistable-place cells 0.93–1.00; R mirrored. Mean-field per-place l* vs simulated l (16 cells with l* > 1): mean abs error 0.19, max 1.35, correlation 0.978; cells with l* = 0: |l| ≤ 0.17 (ρ 0.50–0.54). **The 8 body-row cells and their neighbours remember because of their own morphology (G_morph 4–24); the far cells carry no handedness at ρ = ½ (head/tail: mean ρ 0.52).**
## (d) Hysteresis (continuation of a multiplier s on π_ψ, 1500 tu per step, up 1→6 and down 6→0)
No hysteresis loop (up/down differ by < 1e−3 at every s); the body never leaves L, even at s = 0 (morphology alone holds it). For the cells without morphological evidence (far cells), |l| rises smoothly from 0.07 (s = 1) to 0.17 (1.5), 0.44 (2), 1.07 (3), 2.2 (6): a smooth (field-biased) onset at s ≈ 1.5–2, predicted 4r-crossing of G_mem(s): s* = (4r/k_hβ − π_d)/(π_ψ w̄²) = 1.61 ✓. The bistability onset is that of a biased pitchfork, not a first-order transition.

## Verdict
"The body remembers while a cell forgets": **YES** for the isolated cell (forgets, rate 0.03) and for the body (remembers, 0/20), **but the memory is morphological, not carried by the memory ligand**: with an isolated-cell-safe parameter set the memory channel alone is sub-critical (G_mem 0.25 < 4r).
