# Stage 6.11 Parameter Dictionary

Generated by `code/generate_parameter_dictionary_611.py` directly from `flock_sim.model.ModelParams`, `common_611.py`, `moving_flock_611.py` and (where noted) the phase-scan/gate data files. ## 1. Base active-inference physics (`flock_sim.model.ModelParams`)

Frozen since Stage 6; simulator-side only, never touched by 6.11's additions except beta/precB/precC, which are set via the (beta, s) resolution below.

| field | default value | meaning |
|---|---|---|
| `nu` | `4` | Number of cardinal heading states (up/down/left/right). Fixed throughout Stage 6-6.11. |
| `vm` | `4.0` | Diagonal self-term of the base R matrix (`base_R`): weight favouring heading persistence for a bird observed at its own last heading. |
| `ca` | `2.0` | Collision-avoidance override magnitude: `R[o,s] = -ca` for the (observed-heading, own-heading) pairs in `SLOT_OVERRIDES` at the partner's occupied slot -- the model's separation term (flock_sim/model.py). |
| `fc` | `1.0` | Off-diagonal alignment weight: `R = fc * (UV4 @ UV4.T)` before diagonal/overrides -- the model's heading-alignment (cohesion-of-direction) term. |
| `beta` | `1.0` | precAbird: inverse-temperature (precision) of the neighbour-heading observation likelihood `neighbor_likelihood` -- how sharply a bird's *perceived* neighbour heading concentrates on the true relative geometry. NOT a spatial parameter. |
| `precB` | `15.0` | rho: heading-transition precision. Every column of `B[:,:,u]` is `softmax(precB * one_hot(u))` -- how deterministically a chosen action `u` is realized as the next heading. |
| `precC` | `3.0` | omega: preference precision. Peaks the goal-prior over a neighbour's last-observed heading in `preference_vector`. |
| `alpha` | `8.0` | SPM generic-solver policy-precision hyperparameter (`policy_posterior`'s self-tuning fixed point, `W = alpha/(spm_beta - u.G)`). |
| `spm_beta` | `4.0` | SPM generic-solver beta constant (distinct from the flocking `beta`/precAbird above). Denominator offset in the same self-tuning fixed point. |
| `n_iter` | `4` | Number of precision self-tuning iterations per policy_posterior call. |
| `n_lookahead` | `2` | T: policy length / lookahead horizon used when building G_table/Risk_table (flock_sim.active_inference.build_model). |
