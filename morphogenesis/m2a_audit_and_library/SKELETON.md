**State and map.** One-bin map of the D-step: state x = [beliefs v (64); belief velocity (64); action (48 = 16 positions + 32 secretions); previous action (48, the one-bin action history that the engine carries)] = 224 dimensions, with the absolute-bin clock at b = 320 (s ≈ 1, so the map is autonomous). Jacobians by central differences at two step sizes (1e-4, 1e-6), computed with the state-exporting engine (bit-identical to SPM12 `spm_ADEM`, tests/test_engine_equivalence.py). "Observable" = the action blocks (positions, secretion and their one-bin history); "hidden" = beliefs and their higher order. Eigenvalue μ per bin, rate = log|μ|.

## D2 — is the period-2 cycle a model or a scheme property? **UNRESOLVED**
1. *Eigenvalue near −1?* Yes: μ = −1.536 of the one-bin map on the sustained-DH state (a flip, |μ| > 1), with the period-2 monodromy stable (0.823). The cycle is a flip (period-doubling) of the one-bin map, and the unstable mode lives in the action / previous-action blocks, which is where the engine's one-bin delay between sensing and action sits.
2. *Finer integration.* `spm_ADEM` has a sampling/integration step `M(1).E.dt`; our engine copy accepts it (embedding, integration and the clock all in sub-bins, continuation from the class-0 adult state). **It is not a usable refinement here**: with m = 2 or 4 sub-steps the unperturbed adult state stays at its fixed point, but *any* perturbation (a 1e-3 position pulse, no DH) diverges exponentially (positions ~1e32 for m = 2, ~1e100 for m = 4), and the sustained-DH runs fail with NaN in `expm`. The scheme's per-step loop gain does not decrease with the step, so the engine does not converge as dt → 0 (the instability threshold is a property of the discrete scheme). A rerun of sustained DH with finer integration was therefore **NOT DONE** (the failed runs are the evidence); no claim is made about the continuous-time system.
3. *Onset in the D3 ε scan.* Cycles occur at DH ε = 0.35 (up-sweep, amplitude 0.62) and ε = 1.0 (0.30), and at DT ε = 0.3 (down-sweep, 0.25), never in the precision scan; ε = 0.3 and ε = 0.4 on DH are fixed points. So the cycle is not specific to DH (it appears under DT), is born with finite amplitude at isolated parameter windows, and coincides with transitions of the role map — a property of how these attractors are reached, not a single bifurcation point.
**Conclusion: UNRESOLVED.** Evidence for a model-level mechanism: appears in two families at distinct ε, finite amplitude, tied to role transitions, stable monodromy. Evidence compatible with a scheme artifact: the unstable direction sits on the delayed-action block and finer integration is not available to test it. Distinguishing them needs an integrator that converges in dt (not done).

## D5 — edge tracking toward the saddle (one direction; 196 runs ≤ cap 200; PROVISIONAL)
Direction: global ligand-4 secretion pulse on the class-0 adult base (D4 SHAPE-SWITCH threshold 20.9, bracket 20.71 / 20.90, 1 %; below: FATE-SWAP, above: class 1). Method: bisection on the interpolation parameter between the two post-pulse 224-dimensional states (12 bisections first hop, 7 later), a trial classified by running 20 bins and testing d_pair to class 0 < 0.25; the bracketing pair then advanced 8 bins and the bisection repeated (21 hops, `data/v2/d5/edge_hist.json`).
* **Edge state (hops 10–14, stable to 3e-3):** shape between the classes — **d = 0.284 to class 0 and 0.188 to class 1**; roles (slot of cells 0–7) `2 1 3 0 4 5 6 7`; belief maxima 3.0 / 2.7 / 3.0 / 2.9 / 2.9 / 2.7 / 2.9 / 1.8 (cell 7 has the weakest identity belief and its belief argmax is ambiguous between slots 3 and 4: the undifferentiated cell of class 1 is already forming); per-bin speed 0.0025–0.008 at hops 11–14.
* **Unstable eigenvalue(s):** Jacobian at the midpoint of hops 11 and 14 (residual |f(x)−x| 1.2e-2 and 2.8e-3): **exactly one unstable eigenvalue, μ = 1.68 (hop 11), 1.66 (hop 14); rate +0.51/bin**, the next largest 0.919; the unstable eigenvector is 88 % belief block and 7 % position-action. A saddle with a **one-dimensional unstable manifold**, so the class-0/class-1 boundary is a codimension-one surface and the edge state is its saddle point (approximate: not a converged fixed point).
* Hops 15–20: the bracket was lost (the pair fell into class 0 at the finite precision of the bisection, gap 3e-4 → 5e-11); the edge state above is the last stationary one. One direction only; the saddle reached from other directions is NOT DONE.
