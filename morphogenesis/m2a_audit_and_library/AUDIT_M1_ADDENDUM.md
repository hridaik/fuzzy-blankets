# AUDIT_M1_ADDENDUM.md — formal corrections to Stage M1 ("protocol v1")

All M1 data and conclusions are labelled **protocol v1** from here on; everything produced in M2a after the audit is **protocol v2** (absolute developmental clock, continuations, canonical zero noise). This addendum records what v1 got wrong or could not claim. M1's own files were not modified.

## Corrections (ESTABLISHED unless noted)
1. **AN never applied.** M1's `run_withdrawal.py` recorded the intended cell but passed `cells=[]`; every AN run is bit-identical to DH (80 pairs checked, AUDIT_M1 0.1c). M1's AN rows are DH replicates. Corrected below (item 6) under v1 settings and in WITHDRAWAL_V2.md under v2.
2. **M1 kicks and ADULT conditions were re-developments.** They were new `spm_ADEM` runs started from a stored state, with the developmental ramp restarted at s ≈ 0 and all generalised coordinates reset. v2 kicks/ADULT are continuations of the full state (R0.2). Consequence (v2 vs v1): v2 finds NEW-FORM end states after large position kicks (6/200, all in the second shape class) and DH on a mature body returns to the same roles (0/20 relabelled), whereas v1's ADULT DH relabelled 20/20.
3. **M1's clock was N-coupled.** Census at N = 512 (s(b) = 1 − exp(−2b/512)), withdrawal and sham at N = 1024 (s(b) = 1 − exp(−2b/1024)), sustained twins at N = 512. Comparing end states across these horizons was apples-to-oranges for transient quantities, and an unperturbed N = 1024 run relabels vs the N = 512 census in 9/20 individuals. The published schedule is T_dev = 32; with it the census contains a second shape class that M1's slow clock hid (CENSUS_V2.md).
4. **M1's "noise floor" never operated.** The process noise is identically zero (`G(1).V = exp(16)` → `spm_DEM_z` returns zeros; bit-identical runs for different noise seeds). M1's "3.35e-4 noise floor" and the stationarity threshold derived from it (3×) were not noise-based. Individuals differ only in initial beliefs.
5. **M1's stationarity times were ramp-driven.** "Bin 246 for all 250 individuals" is the bin at which ramp-tracking speed drops below 1e-3 on the shared trajectory; with the ramp frozen the criterion fires at bin ~35. In v2 (ramp saturated by b = 320) stationarity is state-driven (bin 178–260).
6. **M1-comparable AN re-run (v1 settings, EXACT: N = 1024, timings 64 / 332 / 332, ADULT = restart from the census state, 20 individuals, AN cell = individual index mod 8 passed as the only perturbed cell; 20 sustained twins at N = 512; matched unperturbed twins reused).** `code/v1_an_rerun.py`, `code/v1_an_analyze.py`, `data/v1_an/`.

Sustained AN twins differ from the unperturbed shape by d_pair 0.017–0.141 (median 0.09), below the v1 τ_pair = 0.25 in 20/20: **a single anomalous cell is compensated in shape under sustained application** (consistent with m0c's finding that it "washes out"). Reversion of shape is therefore uninformative for AN; its effects are in roles (13–17 of 20 individuals relabelled under v1, a mix of the perturbation and the re-development). **Formal correction of M1 WITHDRAWAL.md:** "AN 60/60 REVERTED, identical to DH" is replaced by: AN was not tested in v1; with the cell actually applied, AN is shape-neutral under sustained application, took effect in 60/60 runs, and relabelled 46/60 (77%).
7. M1's K3 ("belief reset") and sham results hold only for the restart protocol. M1's finding of "one stable form" was specific to the slow clock and to 50 secondary individuals; the canonical clock finds a second class in 3/50 secondary individuals.
