# ENGINE_SPEC.md — continuous-time active-inference morphogenesis engine (T1.1–T1.3)

Code: `code/engine.py` (JAX, float64, CPU). Tests: `tests/test_engine.py`. Labels: ESTABLISHED / PROVISIONAL / NOT DONE.

## 1. Model (as implemented)
Cells `i = 1..n`; state per cell: position `x_i ∈ R²`, secretion `c_i ∈ R^nc` (nc = 4 in the vanilla model; 5 with the memory ligand; more with multi-scale signalling), identity logits `mu_i ∈ R^n`, and — only when K > 1 body plans exist — plan logits `zeta_i ∈ R^K`. Template: target positions `X*_z (2×n)`, codes `C*_z (nc×n)`, and expected field `Λ*_z (nc×n) = Σ_j C*_z[:,j] exp(-κ_ch |X*_z[:,i]-X*_z[:,j]|)` for each plan `z`.

Sensations of cell i: `s_x = x_i` (switch `pos_on`), `s_c = c_i`, `s_λ = τ(t) · [ c_i + Σ_{j≠i} (c_j + ext_j) exp(-κ_ch |x_i-x_j|) ]` (the `j = i` term has kernel 1; `ext` is the exogenous secretion used by interventions; `κ_ch` is per channel).
Predictions: `p = softmax(mu_i)`, `w = softmax(zeta_i)` (1 if K = 1); `g_x = Σ_z w_z X*_z p`, `g_c = Σ_z w_z C*_z p`, `g_λ = τ Σ_z w_z Λ*_z p`.
Per-cell free energy (sensory part) `F_i = ½ [π_x|s_x-g_x|² + Σ_ch π_c,ch (s_c-g_c)²_ch + Σ_ch π_l,ch (s_λ-g_λ)²_ch]`; perception adds `½ π_prior |mu_i|²` and `½ π_ζ |zeta_i-ζ0|²`.
Clock `τ(t) = 1 - exp(-2t/T_dev)`, `T_dev = 32`, absolute time (continuations never restart it).
Flows (gradients by `jax.grad` of the **own-cell** `F_i` w.r.t. the cell's **own** variables, others held fixed — the published restriction `R`; gradients pass through the true process, including the kernel's dependence on `x_i` and the self term):
`dmu/dt = -k_mu (∂F_i/∂mu + π_prior mu)`, `dzeta/dt = -k_mu k_ζ (∂F_i/∂zeta + π_ζ(zeta-ζ0))`, `dx/dt = -k_a ( r ∂F_i/∂x + π_a,x x )`, `dc/dt = -k_a ( r ∂F_i/∂c + π_a,c c )` with `r = π_act/π_ref`.
Noise (optional): additive `σ_x dW` on `x`, `σ_c dW` on `c` (and `σ_mu`, `σ_z`), independent per cell, counter-based: increment of cell `i` at absolute step `k` = `normal(fold_in(fold_in(key, k), i)) · sqrt(dt)`. Twins sharing `key` and `dt` have identical noise; an intervention consumes no random numbers (ENGINE-level CRN; verified in NOISE_AND_CRN.md).

## 2. Deviations from the task statement and from SPM's scheme (declared)
**D0 (found by the T1.4(a) check; the task's F omitted it).** The published `spm_ADEM` scheme drives *action* with (i) its own sensory-error precision (`G(1).U = exp(2)`, perception uses `exp(3)`) and (ii) a prior on the action variables themselves (`Pa = exp(-2)` on positions and secretions). Without these the oracle's adult state is not stationary under the task's `F_i` (action residual 0.53 at the oracle's reference phenotype). Fitting the action-side weights to the oracle's stationarity (null-space of the stacked gradient columns at its adult state) gives: equal weights on the three sensory channels and prior/sensory ratio `ρ = 0.012210 = e^-4 / 1.5` (ratio fitted to 3 digits; secretion residual then 1.7e-8, position residual 5.6e-4). The engine therefore uses `π_act = 1.5·e²`, `π_a = e^-2` (vanilla defaults) — **the factor 1.5 is a fit, its origin in `spm_ADEM` (generalised-coordinate precision structure) was not derived: PROVISIONAL**. The perceptual prior also includes SPM's fixed `Pv = e^-8` (`π_prior = e^-2 + e^-8`), which explains the residual 1e-3 of the belief gradient at the oracle state. After these two changes the engine's adult state matches the oracle's to `d_pair = 8.7e-5` (FAITHFULNESS.md).
D1. First-order gradient flow instead of SPM's generalised coordinates (embedding order 2, smoothness s = 1): no velocity-level prediction errors, no D-operator coupling.
D2. No one-bin action delay and no Gauss-Newton `spm_dx` (local-linearisation) step: time-continuous, integrated by RK4.
D3. Process noise is *additive Langevin noise on `x` and `c`*, not SPM's precision-weighted smooth noise on the sensory channels (the oracle's canonical runs have zero noise). Noise is OFF in T1 and for fixed-point work.
D4. Template field `Λ*` is computed from each plan's own geometry with per-channel `κ` (identical to the published `P.c` when `κ = 1`).
D5 (testbed only, flagged per variant): positional channel OFF removes `F_x`, and `π_a,x` is set to 0 so the body has no absolute anchor (translation invariance); the secretion prior `π_a,c` is kept.
Add-ons present but **OFF by default and uncalibrated** (T2g): `omega` (chiral active motility, rigid rotation of every cell about the centroid), `turnover_rate` (cell turnover; parameter only, no code path).

## 3. Integrators (T1.2) — ESTABLISHED
* Deterministic: classical RK4, fixed step, `lax.scan`. Observed order (vanilla 8-cell, T = 40, error vs dt = 0.00125): **≈ 4.0** (successive ratios 4.09, 3.96, 4.07; the first halvings are in the pre-asymptotic regime). Fixed points identical to 4e-14 across `dt ∈ {0.02, 0.01, 0.005}`; `dt = 0.04` converges over the transient (error 3e-8 at T = 40) but is beyond the stability limit at the stiffer adult state (drift residual 2, see below). See FAITHFULNESS.md / `data/t12_convergence.json`.
* **Stability limit:** the adult Jacobian has spectral radius ≈ 75 (calibrated k), so RK4 needs `dt < 2.78/ρ ≈ 0.037`; the engine default is `dt = 0.02`. A larger `dt` does not merely lose accuracy: at `dt = 0.02` with `k_a = 2.5` (`ρ = 155`) the integrator landed in a *different* state. Every new template, precision setting or intervention that stiffens the problem must re-check `dt·ρ < 1.5`. (The relational and 24-cell variants have their own ρ, recorded in TESTBED_SPEC.md.)
* Stochastic: RK4 drift + additive Euler–Maruyama noise increment (strong order 1 for additive noise). Convergence of the stochastic scheme is reported in NOISE_AND_CRN.md.

## 4. Time calibration (T1.3) — ESTABLISHED (fit), 2 scalars
Targets, measured with identical operational definitions on 12 oracle individuals (`code/calib_targets.py`): within-class merging time constant (max pairwise permutation-invariant distance, log-linear fit over bins 40–120) **7.85 bins** (CENSUS_V2 quotes 6.5 with its own fit window; the same definition applied to both engines is what matters), time for the mean maximum belief to reach 0.5: **10 bins**, 0.7: **21 bins**. Grid over `(k_mu, k_a)` (`code/calib_time.py`, 25 + 12 + 12 points); objective: RMS log-ratio of the three targets. **Chosen: `k_mu = 1.4`, `k_a = 1.2`** → merging 7.68, t₀.₅ = 11, t₀.₇ = 22 (RMS log error 0.063; the optimum is flat: (1.2, 1.8) gives 0.063, (1.4, 2.5) 0.064). Larger `k_a/k_mu` was rejected because it raises ρ (stiffness) with no gain in fit, and because the basin reached from the oracle initial beliefs depends on the ratio (e.g. `(k_mu,k_a) = (1,1)` and `(0.3,1)` end 0.05 from the oracle phenotype in a *different* stationary state). One engine time unit therefore ≈ one SPM bin.
Consequence to remember: the basin structure of the engine depends on `k_a/k_mu`; the faithfulness claims are for the declared pair only.
