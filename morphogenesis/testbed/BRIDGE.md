## 6. Cross-cutting validation discipline (all KEEP)

Held-out evaluation for any selectivity claim; no per-candidate or per-stream maxima as evidence (winner's-curse note); state-clustered aggregation; calibration of thresholds on uncontrolled data only; frozen thresholds before outcome scoring; no-leakage tests that forbid inference-side modules from importing simulator internals (`stage6_5/boundary_inference/tests/test_no_lattice_leakage.py`, `stage6_7…/tests/test_no_topology_leakage.py`) — the testbed's OBSERVABLE/HIDDEN loader (T2f) is the analogue.

## TESTBED REQUIREMENTS (T2 must satisfy; each is checked in `tests/` or a named deliverable)

1. **R1 Noise > 0 option with a canonical operating level** (T2e); a **noise = 0 deterministic mode** for bisection and Jacobians. Needed for M1–M3, E6, otherwise covariances are degenerate.
2. **R2 CRN-pairable noise**: one independent seeded stream *per cell*, indexed by absolute step (counter-based PRNG `fold_in(seed, cell, step)`), so twins are bit-identical until an intervention and no intervention-dependent code consumes draws. Verified in T2e.
3. **R3 Natural uncontrolled ensembles** for plan A, plan B and the chiral variant: declared size and length, plus a *disjoint* validation ensemble (for I4/E3/R1 calibration). Stationarity and decorrelation time reported (M2).
4. **R4 Per-frame ground truth**: cell IDs (permanent), alive mask, membership (all alive cells; connected-component labels at a declared radius), role = argmax place belief, plan belief, free energy, extrusion/split flags (I1, I5, I6).
5. **R5 Ground-truth influence relation**: autodiff Jacobian blocks of each cell's flow w.r.t. other cells' states at declared sample frames, plus the kernel weights (C1, C2), with the relation documented in ENGINE_SPEC.
6. **R6 Independent states**: enough noise-distinct bodies for state-clustered statistics. The vanilla 8-cell body is one body up to relabelling (M2a), so effective n is the number of independent natural-ensemble members, not draws.
7. **R7 State export/restore** of the complete dynamical state on an absolute clock (needed for M3, E1, continuation protocol of PROTOCOL_V2).
8. **R8 Intervention API with separate forcing and release windows**, finite duration, declared region (disc in body frame); a sham with identical RNG consumption (E1, E5).
9. **R9 Relaxation timescales reported** (Jacobian) so that durations, release windows and sample spacing are derived from the substrate, not copied from the flock (`d = 8`, `R_RELEASE = 24` DROPPED).
10. **R10 Blind/audit tiers**: OBSERVABLE tier carries only what an outside observer sees (positions, secretion/ligand fields, cell type colours); HIDDEN tier carries beliefs, plan, free energy, Jacobians. A loader refuses hidden access without an explicit audit flag (analogue of the no-leakage tests).
11. **R11 Rigid-motion-invariant observables** when the positional channel is OFF (body may translate/rotate): all shape comparisons must be done up to rigid motion (and, for the chiral variant, with reflections explicitly *not* quotiented).
12. **R12 Geometric split/extrusion definitions** declared and validated against ground truth (I6).
13. **R13 Reproducibility**: seeds, versions and data manifest recorded; engine bit-reproducible on one machine.
