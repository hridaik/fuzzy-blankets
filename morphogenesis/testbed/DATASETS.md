## T3.4 IDENTITY-STRESS dataset — ESTABLISHED
60 matched triplets (event run, matched untreated twin, sham), 300 time units each (frame every 5), all at sigma 0.02, hidden random arena pose per body, 6 seeds (300–305) per condition:
| scenario (opaque code in the package) | definition | n groups | event arm outcome at 300 units (twin) |
|---|---|---|---|
| replace1 | one uniformly random cell replaced at t = 50 | 12 (L, R) | complete body 6/12, DEFECT 6/12 (twin: complete 12/12) |
| replace6 | six random cells replaced, one every 40 from t = 50 | 12 | DEFECT 12/12 |
| extrude | one random cell pulled 8 units outward at t = 50 | 12 | DEFECT 12/12 |
| cut | random arena line through the centroid, fragments separated by 7 at t = 50 | 12 | DEFECT 12/12 |
| fuse_LL / fuse_LR | two bodies 9 units apart from t = 0 (twin: 40 apart) | 6 + 6 | two bodies 11/12, merged into one 1/12; neither intact |
(L/R = the two strains; the package labels are opaque.) CRN verification on the whole dataset (`stress_check.json`): max |position difference| between the event arm and its twin **before the event is exactly 0.0** in all 60 groups; the sham arm equals the twin **bit for bit (0.0) in all 60** groups; after the event the median final divergence is 0.7 (replace1), 4.8 (replace6), 2.7 (extrude), 12.5 (cut), 31 (fusion). Placements are random by construction (declared): there is no designed placement grid; `event_xy` is not provided in the package. The rates of Part I events are one event type per run (not a Poisson process).
**SWITCH dataset (T3.4): NOT PRODUCED — Gate S failed** (no below / at / above-threshold runs exist because no switch exists).

## T3.6 blind package v1 — `morphogenesis/testbed_blind_v1/` — ESTABLISHED
* **Content:** OBSERVABLE tier only; levels O1 (tracked cells with permanent ids), O2 (unlabelled point clouds, rows shuffled each frame), O3 (96 × 96 two-reporter images, PSF 0.5, peak SNR 20); 740 runs (560 untreated, 180 in 60 matched triplets) × 3 levels = 2 220 npz files, 220 MB; `catalog.csv`, `split_manifest.json`, `DATA_DICTIONARY.md` (written as an experimenter would), `README.md`, `LEAK_CHECK.md`.
* **Opaque labels:** strains S1/S2, conditions N0 and P1–P6, run names without meaning, the four secreted levels in a package-wide shuffled order, two reporter channels unlabelled; the mapping is in `data/blind_v1_hidden/mapping.json` (outside the package).
* **Leak checker** (`code/leak_check_v1.py`, result in the package `LEAK_CHECK.md`): scans every file name, text file and npz key for 36 forbidden patterns (slots, beliefs, plan, template, mechanism, chirality / situs / fate / mirror / handed, receptor / gain / migration, actuator names, ground truth, …), restricts the allowed array keys per level, and checks that labels are opaque, O2 carries no ids and is shuffled, and the body pose varies across runs: **PASS, 0 findings** (after fixing two wording hits in the first draft). It cannot check whether the NUMERICAL data allow inference of withheld facts.
* **Split manifest:** development (calibration natural bodies; stress bodies with seed not divisible by 3), held-out bodies (validation natural bodies; stress seeds divisible by 3), held-out conditions (the two fusion protocols, all runs), held-out actuator locations: **not available** (no actuator-location dataset because of Gate S).
* **Known limitations (stated in the dictionary):** one noise level; 24 or 48 cells; the dataset contains no switching experiment; bodies in untreated runs are intact by construction (windows ≤ 1 600 units); the two strains are separated by the strain code (a labelled contrast, not a hidden one).
