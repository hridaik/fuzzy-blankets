## Observation levels
O1 (tracked cells, 7 levels: the 4 structural signals, the two memory-sector secretions and the reporter, **opaque column order**, 3 % multiplicative noise, position noise 0.02) — the reporter is always observable, as an opaque column; the memory ligands are observable in O1 and in O3b (one memory ligand as 4th image channel). O2 (unlabelled point clouds, shuffled, 5 columns: no memory ligands). O3a (3 image channels: two structural signals + reporter), O3b (O3a + one memory ligand); 64 × 64 pixels, PSF sd 0.5, peak SNR 20, window ±12 (±30 for merge runs).
Actuators (opaque): light channels L1–L5 (two memory-secretion lights, structural secretion, receptor gain, migration; assigned by a random permutation), pipette and bath with reagent codes R1–R6 (random permutation of the six secreted signals).
## Hidden tier (outside the package)
Per run `blind_v2_hidden/<run>_hid.npz`: t, l, ρ, f, q (float16), place energies (float16), memory secretions d, reporter e, true positions, alive, cell ids; `<run>.json`: meta (state, centres, doses), events, hidden pose, private actuator map. `mapping.json`: column permutation, light labels, reagent codes, condition codes. `hidden_covariance.json`, `hidden_influence_{a,b}.npz`: influence matrices (Jacobian block norms) and linear-noise covariance diagnostics at both states (condition number 4.3·10⁵ on the 789 non-neutral modes; MEMORY_V3.md). Caveat: the stored f is computed from the stored state without the exogenous light (so it omits u during pulses); the pulse itself is in the run's treatment metadata.
## Leak checker (`code/leak_check3.py` → `testbed_blind_v2/LEAK_CHECK.md`)
Forbids (case-insensitive, in file names, text files, array keys): memory, handedness, chirality, situs, laterality, reporter, slot, belief, plan, fate, template, mirror, state a/b (and "state(s)"), plus v1's list (mechanism, latent, hidden, posterior, softmax, logit, zeta, orbit, role, μ, receptor, gain, migration, bias, precision, free-energy, attractor, ground-truth, jacobian) and v3 additions (ratiometric, paracrine, quorum, toggle). Structural checks: only the allowed array keys, opaque condition/arm labels, O2 without ids and shuffled, pose randomised (centroid sd 1.68). **Result: PASS, 0 findings** (2,056 files). The first draft of DATA_DICTIONARY.md failed (it used "template" and "mechanism" in its "not provided" paragraph) and was corrected.
## Limits (PROVISIONAL / NOT DONE)
* Natural ensembles come from 130 bodies per state; effective independent samples assume the pilot ACF (one pilot seed).
* SWITCH runs are single noise realisations; "at threshold" runs succeed about 50–90 % under noise (SWITCH_V3.md), so these runs are labelled by amplitude only.
* Observer-side analyses (does the observable data identify the reporter pattern, the memory signal, the stable states?) were NOT done (out of scope).
