## Unsealed mapping (needed to read everything below)
Package column → hidden quantity: **c0 = the reporter e**, c1 = structural code ch2, c2 = structural code ch1, c3 = structural code ch3, **c4 = memory ligand A, c5 = memory ligand B**, **c6 = the axial gradient (structural code ch0)**. Lights: L1 = migration, L2 = structural secretion, L3 = memory-A secretion (pushes b→a), L4 = memory-B secretion (pushes a→b), L5 = receptor gain; so the analyst's **T3a/T3b/T4a/T4b are the memory-secretion lights** (a = 4/g, b = 16/g pulse class), the X-conditions are decoys / other devices (Xsec, Xrg, Xmig, Xbath, Xmbath_low/high, Xmpipette, Xpipette). Reagents: R1 = c3, R2 = ch1, R3 = ligand A, R4 = ligand B, R5 = ch2, R6 = ch0. States of the package: "a" = reporter on the +y body row (limb side) with ligand A high; "b" = the other. The body (positions, types, place beliefs) of a body id is **bit-identical in states a and b** (130 clone pairs, max |ΔX| = |ΔC| = |Δμ| = 0.0): the states differ only in the memory/reporter variables.

## A7 Anticipation
True timing in the 49 switched runs (frame interval 2 tu): ligand crossing (dA vs dB) is 2 tu after the ρ crossing (q10 2, q90 4); reporter flip 2 tu after (−0.4 … 4); **reporter flip minus ligand crossing: median 0, q10 −4, q90 0; the reporter is later than the ligands in only 8 % of runs**. So the memory ligands do **not** lead the reporter at the dish level (both are first-order lags of ρ with the same rate 0.4); the only lead is ρ itself (hidden) over both, ≈ 2 tu = one frame in the 2-tu runs, 0.4 frame in the 5-tu runs, 0.02 frame in the natural runs. **Was the negative result determined by sampling? Yes — and also correct at the observable level**: the lead is ≤ one frame at the best sampling (2 tu) and unobservable at 5 and 100 tu; additionally the analyst's change time is delayed by ≈ 50 tu of window, so any lead below ≈ 50 tu is undetectable by construction. Truth: no observable leads another by more than the frame interval; ρ (hidden) leads by 2 tu.

Pooling the two states (equal-weight mixture, population) leaves the channel-partition values at 0.0000: the two states differ only in the means of c4/c5 and of the reporter dipole, not in the region means of c0–c3, c6. **The analyst's cross-sectional estimates (0.001–0.074) are therefore upward-biased finite-sample/shrinkage estimates of a true value of exactly 0** for the "good blanket" partitions; their ranking against random partitions (percentile 0.000) is right; the region partitions have true L above or comparable to the null for the same reason they did in the analyst's data (percentiles up to 0.92).
**True module structure** (Jacobian block norms; `module_structure` in the JSON): the memory module (l, d, e) has **zero influence on structure** (∂ẋ, ∂ċ, ∂μ̇/∂memory = 0.0 exactly), structure → memory is tiny (∂ṁ/∂x = 6.5·10⁻⁴; ∂ṁ/∂c = 0; ∂ṁ/∂μ = 5·10⁻¹⁸ at crisp beliefs); the structural block is strongly self-coupled (x↔c 10²; μ↔x,c 10³). The truth is **two modules: memory {l, d_A, d_B, reporter} and structure {x, c, μ}**, one-directional (structure → memory, vanishingly weak). The analyst's split {c4,c5} vs {c0–c3, c6} puts the **reporter (c0) on the wrong side**: it belongs to the memory module — but its region means are exactly insensitive to the memory (the +y and −y row contributions cancel: cov(c0 region mean, c4) = 2·10⁻¹⁹), so no region-mean analysis could have placed it correctly; only its left-right dipole carries the memory. So the split is "right for the observable it could see (the ligands) and unresolved for the reporter".
**True directed influence between the analyst's variable groups** (observable-projected Jacobian blocks, disjoint groups memory ligands / reporter / structural types / axial): **0 at the native time scale for every pair** (the reporter and ligand region means are not driven by structure at linear order; the types ↔ axial coupling shows only through the structural block, norm 0.0004–0.0006 at a 100-tu lag). The analyst's "no directed influence at lag 100 tu" is **correct**; the null cannot be used to validate their directed estimator because there is no true positive to detect in these variables.

## Summary of what the T4 analyst got right and what it could not see
Right: O1/O2 body detection and tracking away from jumps; operation detection at O1; the existence of exactly two persistent memory states (and their detection at all four levels with latency ≈ 50 tu window + filter); the dissociation material (persists) / structure (pattern changes only) / state (changes) in memory-light runs; no anticipation; no directed influence; blankets that are trivially independent.
Wrong or over-read: "mirror-image organisations" (same chiral body, only the reporter row and ligand levels differ); a "third organisation" (a body-specific structural variant orthogonal to the memory state); that C2 "changed" in light runs means a structural change (it is the memory/reporter pattern; geometry bit-identical); the twin "drift" is mostly one body's real slow structural mode, not noise; the apparent leakage structure is trivial; O3 events and C1 proxy are unreliable (resolution).
Data-design limits exposed (inputs to Part B): fixed 100-tu sampling of natural dishes and 5-tu / 2-tu fast runs (lags and the lead are unresolvable), O3 field images without cell resolution, region-mean variables blind to the reporter, one age for natural dishes, a single twin body drifting.
