## B4 — sealed live environment (ESTABLISHED; no control or optimisation run)
Server process (`live_server.py`, separate process, local TCP socket with a one-time token written to a 0600 ready-file; JSON lines; no pickling) and a client library (`live_client.py`: stdlib + numpy only) with the API reset / observe / act / step / end_episode (+ freeze, status). Episodes: a dish from the seed pools (development seeds 5000–5399, held-out 6000–6199); the dish kind is a hidden function of the seed; 100 tu settling is done by the server before the episode starts at t = 0; actuation and observation are in 0.5-tu chunks (`step(dt)` must be a multiple of 0.5). Observation noise is a deterministic function of (episode seed, time, level), so repeated observation at the same time returns identical frames. Lights L1–L5 as in the package (opaque), mask discs / half-planes / all in arena coordinates, raised-cosine ramps. **Budgets**: per episode (simulated time, dose = amplitude × duration × cells in the mask, number of actions) and per session (episodes, simulated time, dose); every response carries the counters; exhaustion raises an error. **CRN / twin / sham**: an episode seed fixes the dish and its random events; episodes with the same seed are CRN twins; `reset(sham_of=episode)` starts a matched sham whose actions are accepted with zero amplitude and zero dose. **Held-out pool locked until `freeze(hash)`** (one freeze per session; hash ≥ 8 characters recorded in the sealed directory). Hidden state of every episode (positions, codes, beliefs, memory variables, reporter, alive mask) is written only to the sealed directory (`episode_xxxxx/hidden.npz` + `episode.json`, mode 0700), never returned. CLIENT_API.md describes the rig without any mechanism.
Tests (`live/test_live.py`, 6 pass, ≈ 30 s): (1) the API surface exposes no internal quantity — every return value (status, reset, 5 observe levels, act, step, end_episode) is scanned for forbidden vocabulary in keys and strings and for non-JSON types, level payload shapes are checked (O1 7 columns with ids, O2 5 columns without ids, O3a 3×64², O3b 4×64², O3c 4×128² uint8), repeated observation is identical; (2) **live trajectories are bit-identical to an offline engine run with the same seed and actions** (L, X, μ, E at the last step compared with `np.array_equal`; steps 4 + 5 + 7.5 tu against one offline call); (3) **sham = twin** (hidden logs of a sham episode with an action vs the untreated twin of the same seed: X, C, μ, L, D, E bit-identical); (4) **held-out lock** (locked before freeze, short hash rejected, unlocked after freeze, second freeze rejected, hash recorded); (5) budget accounting and enforcement (dose = amplitude × duration × cells in mask; time, dose, action budgets; invalid dt, channel, ramp rejected); (6) the sealed directory is mode 0700 and contains the hidden logs, nothing hidden in the client directory, client docs and library free of mechanism vocabulary.
Limitations (PROVISIONAL): the server is single-client / single-threaded and runs one request at a time (measured: reset ≈ 3.6 s with the settled dish cached, ≈ 18 s for a new seed; a 100 tu step 1.6 s; three observations 0.03 s); the dish kind per seed is a deterministic function of the seed (a client that could read the server's code could infer it — hence the separate process, but not a security boundary against a hostile local user); `status()` reveals the development seed range; budgets are operator-set and not calibrated to any control task (none was run).
