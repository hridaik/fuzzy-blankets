# PIPELINE TEST ONLY

This package (testbed_blind_v1) was built from testbed v1, whose model has **no usable control interface** (no L<->R switch, bodies dissolve under operating noise at ~3,300 time units; see morphogenesis/testbed/SITUS_CALIBRATION.md). It exists to test the blind-analysis pipeline and its leak checker. **Do not draw scientific conclusions about controllability or identity from it.** Testbed v2 is in morphogenesis/testbed_v2/ — and its blind package (testbed_blind_v2) has NOT been built because gate G3 failed (see testbed_v2/SWITCH.md).
