# testbed_blind_v1 — blind package v1 (OBSERVABLE tier only)
Levels O1 (tracked cells), O2 (unlabelled point clouds), O3 (images). See `DATA_DICTIONARY.md`. Condition and treatment labels are opaque; the mapping is kept outside this package. `LEAK_CHECK.md` records the automated leak scan; `split_manifest.json` the development / held-out split. 740 runs (560 untreated, 180 in 60 matched triplets), 2220 npz files.
This package contains no analysis and no reference answers.
